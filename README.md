# FIDIM

FIDIMは、長文テキストにおいて読みにくいUIフォントを、読みやすくすっきりとした代替フォントに自動的に置き換えるChrome拡張です。ふぃでぃむ、と読んでください。

## 機能

- Windows環境で `system-ui` によって参照されるYu Gothic UIおよびMeiryo UIを、読みやすい代替フォントに自動置換します
- 置き換え後のフォントはデフォルトで `sans-serif`。設定画面から任意の `font-family` 値に変更できます
- 拡張機能のツールバーアイコンから、ワンタップで有効・無効を切り替えられます
- 設定はChromeアカウントに同期されるため、複数端末でも同じ設定が維持されます

### Chrome Web Store

（準備中です）

### デベロッパーモード（手動インストール）

1. このリポジトリをダウンロードまたはクローン
2. Chromeで `chrome://extensions` を開く
3. 右上の **デベロッパーモード** を有効にする
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、リポジトリのフォルダを選択

## FIDIMを作った背景について

本文表示に使われる、body要素などへのCSS `font-family` の先頭に `system-ui` と書かれているサイトは、ほぼほぼ100%、macOSでしか表示確認されずにリリースされているといって過言ではないでしょう。その指定がされていると、WindowsではYu Gothic UIやMeiryo UIというUI用のフォントで本文が表示されることとなり、結果として、過酷な閲覧体験がもたらされます。macOSではSan Franciscoなので、つまり、なんかイイ感じに表示されるのです。Windowsで悲惨なことになっているなど、想像だにしていないのでしょう。しかし何にせよ、そうした読みづらいサイトは無数にあります。どうすればいい？ もちろん本来的にはサイト側が修正すべきだが、目の前の現実に対してその願いは無力なのです。「あーもう、わかったよ。自分でどうにかするよ。（Fine. I'll do it myself.）」そうして、現実へのカウンターとして生まれたのがこのFIDIMだというわけです。めでたし、めでたし…？

追伸　FIDIMのネーミングは「フォントが読みにくいので、修正しました。（Font Is Difficult, I Modified.）」にも由来しています。

# FIDIM

読みにくいUIフォントを、すっきりとした代替フォントに自動置換するChrome拡張です。

macOSでしか表示確認しないウェブデザイナーたちへのカウンターとして生まれた、Windowsユーザー救済ソフト（半分ジョーク）です。

## 機能

- Windows環境で `system-ui` によって参照されるYu Gothic UIおよびMeiryo UIを、読みやすい代替フォントに自動置換します
- 置き換え後のフォントはデフォルトで `sans-serif`。設定画面から任意の `font-family` 値に変更できます
- 拡張機能のツールバーアイコンから、ワンタップで有効・無効を切り替えられます
- 設定はChromeアカウントに同期されるため、複数端末でも同じ設定が維持されます

## インストール

### ソースからインストール（デベロッパーモード）

1. このリポジトリをクローンまたはZIPダウンロードします
2. Chromeで `chrome://extensions` を開きます
3. 右上の「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、ダウンロードしたフォルダを選択します

## FIDIMについて

FIDIMのネーミングは「フォントが読みにくいので、修正しました。（Font Is Difficult, I Modified.）」に由来しています。

世の中にはWindowsでどう表示されるかを確認せずにリリースされたサイトが無数にあります。特に読み物サイトにおいて確認していないのは致命的で、CSSの `system-ui` がWindowsではYu Gothic UIやMeiryo UIに展開されることを想定していないサイトが多く存在します。サイト側が修正するのが本筋ですが、現実的にはそうもいきません。
